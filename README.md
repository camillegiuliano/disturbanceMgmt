An R package in the [PredictiveEcology](https://github.com/PredictiveEcology) ecosystem,
supporting disturbance and management work in `SpaDES` modules.

**Status: scaffold.** The package's scope has not been settled yet, so `DESCRIPTION`'s
`Title` and `Description` are placeholders and `R/` holds no functions. See
[AGENTS.md](AGENTS.md) for the conventions this package follows and the list of open
decisions.

## Installation

```r
if (!require("remotes")) install.packages("remotes")
remotes::install_github("PredictiveEcology/disturbanceMgmt")
```

## Development

The package is documented with **roxygen2** and tested with **testthat**; the usual
`devtools` loop applies.

```r
devtools::document()
devtools::load_all()
devtools::test()
devtools::check()
```

`NAMESPACE` and everything in `man/` are generated by roxygen2 — edit the `#'` blocks in
`R/`, not the generated files.
